# ordinary-lowercase-words.txt
#
# Words this product will lowercase when a dictation is inserted INTO an
# existing sentence and the word is the payload's capitalised first token.
# Every other word keeps its capital. Under-coverage is a no-op; over-coverage
# is the only direction that can produce a visible mistake, so the list is
# authored conservatively and fails in the safe direction.
#
# Authored by Envious Labs for EnviousWispr. No third-party word list is used
# and no bytes are redistributed, so there is no upstream license to satisfy.
# Built grammatically from closed-class English plus sentence-opening
# open-class words, then validated against a pinned dictation corpus. It is
# NOT a spell-check result and NOT an operating-system lookup, so behaviour is
# identical on every machine and in every locale.
#
# Normalisation applied before lookup:
#   1. Unicode right single quote U+2019 folds to ASCII apostrophe U+0027.
#   2. The token is lowercased with the invariant (non-locale) mapping.
#   3. Surrounding punctuation is trimmed before the lookup.
# Entries are ASCII lowercase letters plus an optional single internal
# apostrophe. One entry per line; `#` starts a comment; blank lines ignored.
#
# NEVER add a proper noun, given name, surname, brand, product, programming
# language, nationality, place, weekday, month, digit-bearing token, acronym,
# or the pronoun `I` and its contractions. Those are enumerated in
# Tests/EnviousWisprTests/Fixtures/ordinary-lowercase-denylist.txt and a test
# fails if any of them appears here.
#
