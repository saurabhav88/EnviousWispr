EnviousWispr is a free, open-source dictation app for macOS. To install it, download the disk image from [enviouswispr.com](https://enviouswispr.com), drag EnviousWispr into your Applications folder, and open it. It takes about two minutes. There is no account to create and no subscription to start.

### Install EnviousWispr

1. **Download the disk image.** Go to [enviouswispr.com](https://enviouswispr.com) and download the installer file, which ends in `.dmg`.
2. **Open the file.** Double-click the downloaded file. A window appears showing the EnviousWispr icon next to the Applications folder.
3. **Move the app.** Drag the EnviousWispr icon onto the Applications folder icon beside it.
4. **Open the app.** Open your Applications folder and double-click EnviousWispr.

Open the app from Applications, not from the disk image or Downloads. An app opened from those places cannot update itself.

### macOS warns me when I first open it

macOS may show a security warning because you downloaded the app from the internet. Click **Open** to go on.

### What setup asks you to do

The first time you open EnviousWispr, it walks you through setup in this order:

1. It downloads the speech model and sets up on-device AI polish.
2. It asks for the two permissions it needs, Microphone and Accessibility. See [Granting Permissions](/help/granting-permissions-microphone-accessibility-and-automation/).
3. On the **Ready to Wispr!** screen, you can change the keybind you hold while dictating. The default is Right Option.
4. A practice box lets you try your first dictation before you leave setup. You can skip it and try dictation in a real app instead.

### Find EnviousWispr after installing

The EnviousWispr icon sits at the top right of your screen in the menu bar, near your system icons. Click it to open settings and history. EnviousWispr also shows in your Dock and in the Command-Tab app switcher like any Mac app, and choosing it there brings its window to the front.

### Keep EnviousWispr in the menu bar only

To hide the Dock icon when no EnviousWispr window is open, turn off **Show app in Dock** under **Settings** > **Appearance**.

### Updates

EnviousWispr checks for updates automatically and tells you when a new version is ready to install. You never need to download the installer file again by hand. See [Auto-Updates](/help/auto-updates/).
