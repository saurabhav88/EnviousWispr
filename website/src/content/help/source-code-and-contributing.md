EnviousWispr is a free dictation app for macOS, and the entire application is open source under the GPLv3 license. You can read every part of the code at [github.com/saurabhav88/EnviousWispr](https://github.com/saurabhav88/EnviousWispr) and check every privacy claim on this site against the code that runs on your Mac.

### What the license lets me do

EnviousWispr is distributed under the terms of the GNU General Public License v3 (GPLv3). It grants specific rights and sets clear boundaries.

- **Use freely.** You may use, study, change, and share the software, including for commercial purposes.
- **Share modifications.** If you distribute a modified version of EnviousWispr, that version has to be open source under the same license terms.
- **Trademarks are excluded.** The EnviousWispr name and logo belong to Envious Labs LLC and are not covered by the open source license.
- **The models are licensed separately.** The GPLv3 covers the application code. The EG-1 polish model downloads separately under its own model license, and S1-mini by Superwhisper comes under its own license too. The speech models are third-party downloads as well.

### Report a bug or ask for a feature

Open an issue on GitHub Issues to report unexpected behavior or suggest something new. If you would rather not post in public, [send feedback from the app](/help/sending-feedback/) instead.

### Contribute code

Send a pull request. A pull request is a proposed change to the code that the project owner can review and accept on GitHub. It can be a bug fix or an improvement.

### Check the code against the claims

Read the source and report any gap between what the documentation says and what the app does. Contributions of every kind make the project more stable and easier to trust.

### Build EnviousWispr yourself

You can compile the app from source on your own Mac. Building needs a Mac with Apple Silicon and full Xcode 26 or later, along with the developer tools mise and Tuist. The repository README keeps the current steps.
